🍉 Fruit Ninja - Pygame EditionA fully functional, arcade-style Fruit Ninja clone built from scratch using Python and the Pygame library. Slice flying fruits, trigger juicy particle splashes, dodge explosive bombs, and test your ninja reflexes!✨ FeaturesProcedural Fruit Rendering: Dynamically drawn fruits (Watermelon, Orange, Apple, and Banana) complete with rotation, texturing, and realistic split-half physics.Arc Physics & Gravity: Fruits and bombs follow authentic parabolic trajectories with adjustable gravity.Glowing Blade Trail: Fluid, fading mouse trail that simulates a razor-sharp ninja blade.Juice Splashes & Particles: Dynamic splash effects matching the color of the sliced fruit.Bomb Hazards: Dangerous metallic bombs with blinking fuses that trigger an instant Game Over if sliced.Lives & Score System: Lose a life if an unsliced fruit falls off-screen, with a 3-life limit before game over.Dojo Aesthetic: Custom wooden-themed dojo UI background and overlays.🛠️ PrerequisitesMake sure you have Python 3.x installed on your system. You will also need the Pygame library.🚀 Installation & RunningClone or Download this repository to your local machine:git clone (https://github.com/taniaeva/Fruit-Ninja.git)
cd fruit-ninja-pygame
Install Pygame using pip:pip install pygame
Run the Game:python main.py
